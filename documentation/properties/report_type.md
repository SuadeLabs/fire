# report_type

---

The **report_type** attribute identifies the supervisory report or template to which an adjustment applies and is a string field.

Supervisory reporting uses named templates; for example, [Regulation (EU) 2024/3117, Annex I, Section 1, page 17][reporting] lists the own funds templates and their codes. FIRE keeps the report identity separate from row and column coordinates so the receiving system can locate the adjusted cell.

It is best to check with your software provider for a full list of applicable report types.

[reporting]: https://www.mfsa.mt/wp-content/uploads/2025/10/ITS-on-Supervisory-Reporting-Regulation-EU-2024_3117.pdf#page=17
