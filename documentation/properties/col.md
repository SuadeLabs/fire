# col

---

The **col** attribute identifies the report column to which an adjustment applies and is a string field.

In FIRE, `col` is the column coordinate used to locate the adjusted cell. For an example of regulatory column codes, see [Regulation (EU) 2024/3117, Annex I, template C 02.00 (Own funds requirements), page 22][reporting], which labels its total risk exposure amount column `0010`.

For example "Column 0010" should be simply denoted as "0010".

It is best to check with your software provider for a full list of applicable row codes by report (this list would be too long to enumerate here).

[reporting]: https://www.mfsa.mt/wp-content/uploads/2025/10/ITS-on-Supervisory-Reporting-Regulation-EU-2024_3117.pdf#page=22
