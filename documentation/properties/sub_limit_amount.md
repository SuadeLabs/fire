# sub_limit_amount

---
Where applicable, represents a specific sub-limit amount established for an instrument or counterparty within a facility.
This field should only be populated where a specific sub-limit applies. It should not be used to represent the overall credit limit of the facility. For the overall facility limit, refer to [**limit_amount**][limit_amount]
