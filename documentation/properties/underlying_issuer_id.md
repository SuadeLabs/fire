# underlying_issuer_id

---

The **underlying_issuer_id** attribute identifies the issuer whose instrument or creditworthiness is the underlying reference for the derivative and is a string field.

For credit derivatives, [ESMA Guidelines for reporting under EMIR, Section 4.16, paragraph 248, page 161][emir] distinguishes a specific reference obligation from a reference entity. FIRE keeps the issuer relationship explicit using the institution's identifier for that issuer.

[emir]: https://www.esma.europa.eu/sites/default/files/library/esma74-362-2281_final_report_guidelines_emir_refit.pdf#page=162
