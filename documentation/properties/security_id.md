# security_id

---

The **security_id** attribute identifies the security instrument that constitutes or represents the collateral and is a string field.

For a regulatory example, [Regulation (EU) 2019/356, Annex, Table 2, field 78][sftr] identifies the security used as collateral in securities financing transaction reporting. FIRE stores the institution's identifier for the security record, which may be mapped to the external reporting identifier.

[sftr]: https://eur-lex.europa.eu/legal-content/EN/ALL/?uri=CELEX:32019R0356#:~:text=Identification%20of%20a%20security%20used%20as%20collateral
