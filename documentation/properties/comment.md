# comment

---

The **comment** attribute is free text used to explain an adjustment or to add context to a worked FIRE example and is a string field.

The [FIRE adjustment schema, `comment` property][adjustment] defines commentary about an adjustment; the [FIRE example schema, `comment` property][example] defines explanatory text for an example. This metadata helps reviewers understand the record and is defined by FIRE.
